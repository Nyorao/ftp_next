# 相对编号搬运：候选机制与预先固定的筛查

## Material Passport

- 类型：代码实验协议与候选模型设计；日期：2026-10-29。
- 状态：科学不变量8项及真实软件短测通过；完整冻结筛查已完成，未达到预设门槛，没有启动本候选的分割训练。
- 输入：既有hard_peer第4500步验证最佳的两个教师、原1496张L与21例valid；不新增单学生基线。
- 问题：同一脊柱的两教师可能相差共同的编号偏移，普通逐像素硬交叉监督会传播整体编号错误。

## 机制和模型

沿用平坦20类学生A与组织/编号学生B及各自EMA，不改变部署主网络A。编号依然是SPIDER的相对序号，不将最低可见椎体改成1，不假定其必为解剖L5。

在弱图像上，从两教师最大类别概率均≥0.8且同属椎体或椎间盘的像素构造类别对应表C。每个至少有16个对应像素支持的预测类别，分别按行和列归一投票；两个方向等权，避免一个大椎体只因像素多而控制偏移。注意，这按预测类别均衡，并非连通实例均衡。

对d∈[-8,8]累加满足`B_ID=A_ID+d`的票。椎体和椎间盘共享d，但从不跨组织搬运。仅当最高票占比≥0.6，且至少两个不同数值编号各有≥16个对应像素支持时接受非零d；否则d=0。该规则交换教师后d反号，无外部真实标签输入。

给A的目标为`q_B(k)=p_B(k+d)`，给B使用相反偏移。背景和椎管保持原概率。越过1…9或11…19的质量丢弃，不循环、不挤到边界类别、不重新归一为高置信度。双方已经以≥0.8置信同意的绝对类别像素保留原目标，避免全图偏移破坏已有共识。此保留规则可能造成局部不连续，需要实测，不能保证解剖连通性。

正式训练若进入下一阶段，使用原置信阈值的硬交叉CE：目标最大值仍须达到0.8（背景0.95），背景权重0.25，按全部像素平均。标签/目标先在完整弱图上生成，再与强图一起CutMix。d=0时目标、掩码和损失严格退化为原hard_peer。监督损失、预热/渐增、初始化和验证选模均保持原协议；主指标仍是单网络teacher1的原生3D Dice。

**可辨识性限制**：搬运只对齐相对编号，不能判定两教师谁的绝对编号正确。如果A整体错、B正确，A方向可能把B也改错。两教师共同错位不可由二者对应恢复。它不应被描述为已知正确锚点的纠错器；L监督负责绝对编号约束。先验证风险与收益，再考虑训练。

## 与已有工作的边界

- [CPS](https://arxiv.org/abs/2106.01226) 已有双向硬伪标签交叉监督。
- [TraCoCo](https://arxiv.org/html/2203.14523) 已有空间位置扰动的一致性和共同训练；本候选改变类别轴，不能把通用平移鲁棒性当新颖点。
- [PAIS](https://arxiv.org/abs/2308.05359) 对类别/掩码质量分数失配动态重加权，说明“伪标签对齐”一词本身不是贡献；其摘要所述机制不等于有序编号轴的共同偏移。
- [2026半监督椎体分割与识别](https://pmc.ncbi.nlm.nih.gov/articles/PMC13030516/) 已明确描述有限FOV下整体编号错位，并结合识别/分割一致性；发现该失效模式不是新颖点。
- [BARL](https://arxiv.org/abs/2510.16863) 已结合双分支标签空间一致性和表示空间区域/实例匹配；不能将“标签空间对齐”这个宽泛表述作为新颖点。此处仅核对其作者摘要的机制范围。
- 通用排列匹配、序列对齐和关系蒸馏都是成熟思想。当前仅提出受序号约束、保留越界不确定性的交叉目标；有针对性的检索未发现完全相同方案，不等于新颖性已证实。

需回答的区别是：在发生共同编号歧义时，能否比**原交叉监督**和**直接弃用变更区域**保留更多正确的细粒度监督，并最终改善预设单网络，而非只保护当前预测。冻结教师筛查不能证明训练有效。

## 冻结教师筛查（首次执行前固定）

复用同一hard_peer checkpoint，严格FP32，CPU4线程，batch8，不更新任何参数。固定抽取256张原L以及全部21例/418张valid；不得用test选择本机制或阈值。没有阈值搜索，配置为上述0.8/16/0.6/2。

1. 报告每方向实际伪标签的正确数、错误数、覆盖、由正确改错/由错误改对、两个教师各自独有正确区域、发生偏移的切片/病例及偏移票。
2. 与仅丢弃“原目标和搬运目标的硬类别不同”区域比较；该控制使用预测决定掩码，无GT。
3. 报告原生3D的A、B、直接平均、A锚定搬运平均、B锚定搬运平均、A锚定弃用平均。诊断平均为`(p_own+q_peer)/(1+sum(q_peer))`；d=0精确恢复原平均。它不用于实际硬交叉损失，也不是单网络结果。
4. 下一阶段最低进入条件固定为：A锚定平均比原平均高≥0.3pp、超过A锚定弃用平均，且给A的伪目标正确前景数至少保留原B的98%、错误前景数不增加。B方向如退化必须明确报告，不能据A方向擅称双向都改善。

若不通过，不把它加入正式训练或按验证反馈反复扫阈值。若通过，先实现hard_peer/弃用/搬运三组匹配的双学生训练，并复用已完成单学生数据。已有valid被反复用于开发，不称其为独立确认；最终结论还需固定模型后的单网络测试和种子复核。

## 启动后的独立审查补充（不改本轮筛查）

纯共同偏移时，搬运目标可以精确等于接收方自己的硬标签。这说明该机制有自确认解，不能把纠正同伴错位自动解释成接收方获得新知识。跨切片聚合或留出当前切片估计偏移只能减少局部循环，并不提供绝对正确的编号锚点；本轮未实现此变体。

结果需分别检查：接收方正确时的重复监督、接收方错误而同伴正确的信息保留、两者原本都错误的恢复。即使通过本轮最低门槛，正式训练前仍应增加“变更区域替换为接收方自身EMA硬标签”的控制，且与搬运共用同一接受掩码。否则搬运与简单自训练无法区分。该补充是新颖性解释边界，不回写已冻结的门槛或更换主方向。

独立审查未发现方向、detach、零偏移或越界概率处理的阻断错误。另两点必须保留：融合Dice包含实际硬CE会拒收的低置信区域；原始边际通过16像素筛选的类别，在删除低支持对端后可能剩余不足16仍参与等权投票，只有最终偏移的两编号锚点另作≥16检查。先例补充：[PIT](https://arxiv.org/abs/1607.00325) 已处理输出排列歧义，但其无语义源次序与这里L定义的编号不同；[RKD](https://openaccess.thecvf.com/content_CVPR_2019/html/Park_Relational_Knowledge_Distillation_CVPR_2019_paper.html) 已蒸馏相对关系，关系传递本身不能作为新贡献。

## 完成结果（冻结协议之后追加）

运行 `outputs/ordinal_transport_probe_20261029/` 在525.36秒内完成，21例/418张valid，256张原L，0次模型更新，未读test。正式运行与软件短测的冻结源码哈希和所有机制阈值完全一致；只有训练诊断抽样数量不同。

| 双教师诊断输出 | 原生3D Dice % | 相对原平均 pp |
|---|---:|---:|
| 原平均 | 80.387943 | 0 |
| A锚定搬运 | 80.484285 | +0.096341 |
| A锚定弃用 | 80.400484 | +0.012540 |
| B锚定搬运 | 80.315785 | -0.072158 |

只在126病例的一张切片触发非零偏移。A方向恢复666个原同伴错误目标，其中311个是两教师都错误、355个是A原本就正确；原B正确目标有20个变为拒收。B方向把867个正确目标改错，独有正确目标从12,706降至12,034，显示不能把单方向对齐解释为双向可靠协作。两个方向合计正确前景目标减少221，错误前景目标增加201（均为224²诊断网格）。

A方向超过弃用控制并通过正确保留/错误数条件，但未达到平均Dice至少+0.3pp的预设要求；该条件保持不变。没有进入长训练，也没有从新测试集挑阈值。完整逐病例差、目标分类及从原生体素数独立重算的报告见 `outputs/ordinal_transport_probe_20261029/report.md`。有限病例重采样区间不包含训练随机性，且只有一个已用于开发的病例变化，不能称推广效果已成立。

下一设计要解决的是**辅助分支不确定的绝对编号不应直接进入对方监督**。可考察只输出组织和相对层级的辅助学生，使共同编号偏移在损失中消去；这仍需与相同掩码的自身EMA、已有关系蒸馏区分，且不能声称解决主学生自身的全局编号错误。该方向目前只是待核验假设，尚未实现或启动训练。
