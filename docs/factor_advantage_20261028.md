## 概率模型

教师 A/B 输出 `p_j(g,k)=a_j(g)b_j(k|g)`。组织分组为背景、椎体、椎管、椎间盘；编号为数据的相对序号，不解释成绝对解剖编号。

```
a(g) = sigmoid(u) a_A(g) + (1-sigmoid(u)) a_B(g)
r0(g) = a_A(g) / (a_A(g)+a_B(g))
r(g) = sigmoid(logit(r0(g)) + v_g)
q(g,k) = a(g) [r(g)b_A(k|g) + (1-r(g))b_B(k|g)]
```

椎体、椎间盘各有一个编号门；背景和椎管无编号门。`r0` 使用原始教师组织质量，不依赖 `u`。实现用未归一化细类概率直接计算，避免零支持组织的条件分布产生虚假质量。

- `u=v=0` 时，数学上等于 `(p_A+p_B)/2`，浮点实现按数值容差验证。
- 仅改变编号门，四类组织概率保持不变。
- 仅改变组织门，各组织内的条件编号分布保持不变。
- 交换教师并翻转门符号，输出不变。
- 三个门取相同值（不仅是零）时，严格退化为该值对应的完整类别混合。这使完整类别门成为因子融合的受约束特例。

这与分别对组织概率、条件概率做简单 0.5 平均后相乘不同；后者通常不等于原始 20 类平均。

## 有标注样本上的学习目标

小型预测器从两教师的概率、组织质量和条件熵预测三路有符号优势。局部卷积与沿头脚方向的上下文只读取概率，不读取图像、患者编号、坐标或额外标注。`(f(A,B)-f(B,A))/2` 后接 tanh，强制教师交换反对称；末层零初始化。

目标是平均点处 NLL 对门的一阶负梯度。对于真实组织 `g`、编号 `k`：

```
delta_t = 0.5 (a_A(g)-a_B(g)) / (a_A(g)+a_B(g))
delta_k = r0(g)(1-r0(g)) (b_A(k|g)-b_B(k|g)) / b0(k|g)
```

编号目标只在相应组织的标注像素上回归；背景权重 0.25。每个有效头分别求加权均方误差，再对头平均。实际门为 `2 * predicted_delta`，固定尺度，不用验证集扫参。该目标给出局部 NLL 下降方向，不保证有限步长、跨患者泛化或 Dice 提升。

完整类别对照使用相同输入描述和卷积主干、一个门，回归 `0.5(p_A(y)-p_B(y))/(p_A(y)+p_B(y))`。记录实际参数量，头的通道数差异如实保留。

## 先做冻结教师探针

复用 hard_peer 的第 4500 步验证最佳 checkpoint，冻结两个 EMA 教师，不训练新的分割学生。先记录 checkpoint 和源码哈希，然后：

1. 只读取原训练预算内 1496 张有标注切片；不读取未标注训练标签。沿用训练几何增强。
2. 同一批教师输出同时训练 flat/factor 两个小预测器。固定 seed42、batch4、800 次更新、AdamW lr0.001、weight decay0.0001、宽度16、梯度裁剪5。不按 valid 选择探针 checkpoint。
3. 仅在训练结束后评估全部 21 例 valid，比较平均、完整类别门、仅组织门、仅编号门、完整因子门。记录原生 3D 主 Dice，以及 union-present Dice。全程不读取 test。
4. 在固定均匀抽取的最多 256 张训练标注与全部 valid 上，报告优势回归相对零预测的 MSE、方向一致性和 NLL，检验训练误差预测能否泛化。
5. 在 valid 的 224² 网格上，用真实标签算一次局部理想方向，作为不可部署的诊断；不得并入方法结果或按此逐像素选择模型。

**筛查门槛（在运行前固定）**：完整因子融合 valid 原生 Dice 至少比算术平均高 0.3 个百分点，并超过完整类别门；前景 NLL 不增加。若不满足，不直接扩展到完整分割训练。单个冻结种子的探针即便通过，也只说明值得继续。

教师已使用训练标注学习过，故路由器训练误差可能过于乐观；valid 泛化检查是最低限度诊断，不能替代患者级交叉拟合。验证集已经用于开发，不能称独立确认。

## 通过筛查后才进行的半监督学生实验

在同一异构双学生架构、预算和种子下，至少比较算术平均软蒸馏、完整类别门、完整因子门。主指标仍固定单个 teacher1，验证选模。推理不保留融合预测器或第二分支。是否获得单网络提升需要重新训练验证，冻结集成提升不等于蒸馏提升。

所有组用中性平均教师的组织置信度生成相同选择规则（前景0.8、背景0.95、背景权重0.25），完整20类软概率与权重先打包，再做与输入一致的 CutMix。损失为全像素平均的加权软交叉熵；不会因细类分歧而退化成整个组织集合，也不会把“新增软监督像素”的收益误归因给门控。教师和伪目标停止梯度；优势预测器只从有标注样本更新。

### 运行中的独立实现审查

2026-10-28 的同模型家族只读审查确认了上述数学不变量，以及恒等式 `delta_flat = delta_tissue + delta_level_of_true_family`；背景/椎管的编号项为零。补充了“全部门耦合等于完整类别混合”和“优势目标可相加”的数值检查。该审查不读取未完成结果，也不修改当前快照。

14 项检查现已通过，日志和源码哈希见 `outputs/factor_routing_checks_20261028/verification_v2.json`。`factor_tissue` / `factor_level` 是同一个已训练三头预测器的推理干预，不是各自独立训练的单因素模型。负NLL导数的数学解释要求真类有正概率支持；两教师都给真类零概率时，代码返回有限约定值，不能称其为该处无穷NLL的真实导数。

两项归因限制必须在后续阶段处理：

1. 因子模型按每个预测头的有效支持分别归一化，椎体、椎间盘的像素因此得到不同于原 flat 头的权重。当前 flat 比较同时改变自由度和误差回归的组织权重，不能把差异全部归于解耦门。若进入后续学习比较，应增加与因子目标匹配总体组织权重的 flat 控制，或对两者采用完全一致的输出分布训练准则。
2. 当前筛查考察完整预测图，后续软蒸馏使用中性教师的组织置信掩码。应在固定路由器上另查实际被保留的监督区域，避免把将被丢弃区域的融合收益当作可传递收益。该补充检查不能反过来修改本轮阈值或既定通过条件。

若探针通过，优先进行**固定教师与固定路由器**的 mean/flat/factor 单学生蒸馏比较，保持学生初始化、监督损失、伪标签掩码、增强和预算相同。先验证信息能否传入预设单网络，再研究在线共同训练；两者不得混在一个实验中归因。冻结探针使用的训练标签已被教师学习过，患者级交叉拟合或独立确认仍未完成。
