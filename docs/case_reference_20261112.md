# 病例中部参考片：三组配对实验实施说明

本轮实现并准备实验，不启动正式训练。已有的“中间片在 20/21 例中达到最多前景类别数”是立项依据，不是本轮性能结果。目标片指正在分割的片；参考片指扫描序列中间片，不将其称为解剖正中矢状片。

## 三组模型

| 组 | 影像输入 | 融合方式 | 单个学生参数量 |
|---|---|---|---:|
| A | `[i-1, i, i+1]` | 原 adaptive | 5,688,640 |
| B | `[i-1, i, i+1, floor((N-1)/2)]` | 四片动态融合 | 5,693,123（+4,483） |
| C | `[i-1, i, i+1]`，独立位置图 p | 三片内容 logits + 位置 logits | 5,688,889（+249） |

全部沿用 32/64/128/256/256 的共享编码器、Mean Teacher、目标片监督、1496 张标注及 3732 张允许影像池。三个融合尺度为 stride 4/8/16，stride 1/2 跳接仅取目标片。B、C 互斥，不叠加文本分支、额外损失、缩窄网络或额外参考片监督。

`F_out = F_i + gamma * (sum_j softmax(logits)_j * F_j - F_i)`。

B 的融合卷积为 `4C -> 4`；第四槽即使与局部片重复也保留。C 每个尺度使用 `Conv1x1(1,16) -> ReLU -> Conv1x1(16,3)`，最后一层零初始化，将位置偏置加在原三片 softmax 之前。新增分支不改变共享骨干初始化和原随机状态。所有组从头训练，B 不自动迁移三片融合权重。

旧配置缺省 `case_reference=none`、`context_position=none`，仍构建原模型；旧模型调用与 format-3 检查点保持兼容。C 的 `position` 为可选接口中的必需实参，形状 `[B,1,H,W]`、范围 `[-1,1]`；B 拒绝位置输入。检查点按保存的配置严格加载，形状不匹配直接报错。

## 数据与增强

- 参考片固定从同病例、同分区、原允许影像池选择，偶数片数取较小中间索引；局部越界复制端点，单片病例合法。
- 位置从验证过的影像几何获得，右端为 -1、左端为 +1，单片取 0。原影像输入顺序保持不变，物理方向反转只影响位置符号。
- 初始化位置数据集时核对影像数组 SHA256、完整片序、每片预处理后的 PNG 对应关系；缺失、含糊或过期几何直接报错。这个过程只读影像。推理端直接从可信影像几何生成位置，无需标签。
- 四片共享空间增强。前三片沿用原强度增强随机流，参考片使用种子偏移 600000101；独立强度扰动后仍只监督目标片。
- CutMix 同时混合所有影像通道及目标。C 的位置图与伪标签一起打包，使用同一供体和矩形，随后拆出；不对位置施加强度扰动。教师使用未混合的位置图。
- 参考片标签不读取。验证集标签仅用于允许的评价与分析，训练期不把类别数量、标签位置或质量标签作为输入。

## 整卷缓存与开销

缓存仅在一次整卷推理调用内生效，按模型和病例隔离；学生训练和教师训练前向均不跨步或跨增强复用特征。每个真实切片只编码一次，B 的固定参考特征跨输出窗口保留。

编码和解码沿用固定微批 8。B 先预编码参考片，因此参考预编码、包含参考片的编码块和尾批都可能引入填充开销。分析逐病例记录实际真实编码数、参考预编码槽位、编码槽位、输出槽位和填充量，不能直接把“每片只编码一次”当作零额外推理成本。

`architecture.json` 记录实际卷积计数得到的学生单目标前向 MAC、模块参数和融合权重形状。该计数不含归一化、插值、softmax、反向传播等操作，不等于完整训练 FLOPs。B 未缓存学生前向卷积 MAC 预计增加约 16.25%，以生成的计数为准。

训练运行记录整体耗时、GPU 型号、峰值分配/保留显存。耗时包含数据校验、训练、验证和保存。整卷分析另记预加载输入后的模型推理时间、卷积 MAC 与峰值显存；该时间排除影像读取及评分，不能当作无干扰的端到端部署时延。

## 筛查与确认

1. A/B/C 顺序运行 seed42、6000 步，每 500 步评价全部 21 例 valid；warmup 600、ramp 1200。以本轮 A 为配对基准。
2. B/C 主 Dice 相对 A 至少 +0.3 个百分点，且 union-present 不降，才通过筛查。通过者中主 Dice 最大的进入确认，完全相同时选计算更少的 C。
3. 确认重新训练 A 与胜出组，seeds42/43/44 各 30000 步；沿用现有长程 warmup 1500、ramp 3000、每 1000 步完整验证。没有候选通过时自动结束。
4. 确认门槛为平均主 Dice 至少 +0.3 个百分点、至少 2/3 种子正向、平均 union-present 不降。该工程门槛不等于统计显著性。

主指标是病例内 GT-present 前景类别 Dice 平均，再对病例等权平均；union-present 包括 GT 缺失但预测出现的类别。最佳 EMA 教师由完整 valid 主 Dice 选择。无 test 调参或 test 评价，不将中断或缺少病例的结果汇总为完成。超时/异常保存失败状态并停止，不自动换 CPU 或重试改协议。

## 机制与配对报告

对三组最佳教师执行完整输入分析；B 额外把第四输入换成目标片、同病例四分之一索引 `floor((N-1)/4)`；C 固定种子打乱病例内位置。打乱在不同模型种子间保持相同，单片保持 0。干预只测模型输入依赖，不证明中间片优于所有参考选择。

按物理扫描位置五等分、目标至原中部参考片距离（≤5、5–15、>15 mm）、原参考片重复情况、端点与非端点分组。干预前后的分组定义不变，避免改变比较样本。

- `native_*`：先汇总病例内该组的原生网格混淆矩阵，再算主 Dice、union-present、椎体/椎管/椎间盘 Dice、同组织编号混淆，以及该组缺失类别的误检比例。
- 其他区域指标：在模型 224×224 网格统计组织区、前景/背景及边界内外侧的像素误差、目标片缺失类别误检、整例缺失类别误检。边界为类别变化处两像素宽带，不解释为毫米距离。
- 保存每例完整原生网格类别指标、组织 Dice 和 20×20 编号混淆矩阵。完整输入的分析主指标必须复现所选验证检查点结果。
- 筛查输出 B−A、C−A、B−C 的病例配对差值和 10000 次病例 bootstrap 区间；确认先在病例内平均三个种子，再对病例 bootstrap，同时列出每种子差值。不会把同一病例的三个种子当作三个独立病例。

探索性分组没有多重比较校正。B 的收益仍可能受额外容量/输入曝光影响；B 主 Dice 上升但误检增加时，优先检查远距离空间混合。两候选均未通过时保留 A，不据一次融合实现失败否定参考影像的所有用法。

## 入口与产物

准备命令只冻结源码、几何清单、配置和开销计数，**不启动训练**：

```sh
/home/zhp/.conda/envs/mamba/bin/python experiments/run_case_reference.py \
  --output-dir outputs/case_reference_20261112
```

以后获得启动指令时，可启动已准备快照，进程后台运行并自动完成筛查、分析及条件确认：

```sh
/home/zhp/.conda/envs/mamba/bin/python experiments/run_case_reference.py \
  --output-dir outputs/case_reference_20261112 --launch-prepared
```

新目录也可通过 `--execute` 在准备后启动；仅做筛查的准备阶段需加 `--screen-only`。目录不覆盖。启动前核对源码/几何哈希、CUDA 可用性与可用显存，执行实现测试并核对三组相同数据清单和完整 21 例。

目录包含 `manifest.json`、`configs/{A,B,C}.json`、`architecture.json`、`code/`、`geometry.json`、`command.json` 和 `status.json`。启动后增加 `run.log`、`launch.json`、`device.json`、`screen/`、`analysis/`、`results.json`、`report.md`；通过筛查时增加 `confirmation/`。进程完成/失败状态和退出码写入 `status.json`。无需持续人工监控。

实现测试使用临时合成数据的短步更新，不属于正式性能实验，不能据此报告有效性。CUDA 检查若因设备不可用跳过，会在正式启动的前置检查中重新执行。

位置条件的文献动机见 [SegMate](https://arxiv.org/abs/2602.23903)；跨片空间对应见 [CSA-Net](https://arxiv.org/abs/2405.00130)。当前实现没有额外对应模块。
