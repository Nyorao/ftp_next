# 编码器 Token／CLS 位置验证

日期：2026-11-10。用户已确认逐词 token 与每类句向量定义，以及8组各6000步预算。

## 实现与实验因素

PSGM-inspired 模块位于共享单片编码器 E2/E3/E4 的编码块之后、下一次下采样之前；修改后的特征同时用于后续编码和跳跃连接。三片继续经原有中心残差融合和解码器，学生和EMA教师结构相同。

- Token：既有冻结BiomedCLIP缓存的第12层有效词token，排除padding及特殊符号。
- CLS：同一提示第12层第0位置的句级向量，每类分别保留；与Token均为768维。
- 视觉LN→64维Q，文本LN→共享64维K/V；类内token softmax，类间使用按有效长度校正的logmeanexp及softmax，形成空间文本特征。
- 拼接视觉Q和文本特征，3×3卷积→GroupNorm→GELU→1×1卷积，经零初始化tanh门控残差返回原通道。
- 所有非A0组创建相同参数；未选融合分支冻结。不同位置的实际参与参数单列，不宣称等有效容量。

共同辅助头：E2/E3/E4注入前的中心片特征分别投影至512维，L2归一化后与冻结的四类文本锚计算余弦分数，温度0.07。仅有标注中心片接受面积池化、类别平衡组织CE，三个尺度先平均，总权重0.1。无全局图像蒸馏。

新增配置：`text_fusion_layout=encoder`、`text_feature_kind=tokens/global_cls/none`、`encoder_text_stage=2/3/4/null`。原e4/hierarchical配置保持兼容。检查点嵌入文本缓存，推理不加载文本编码器。

## 判定与报告

主指标：病例内平均GT存在前景类别，再对病例等权平均。按最佳EMA主Dice选模，同分较早；同时保存并报告6000步。

- 融合筛查：相对A0至少+0.3pp、相对A1至少+0.1pp，Union均不下降。
- 位置偏好：同类表示的候选位置相对另两处均至少+0.1pp，Union均不下降。
- 粒度偏好：同位置T/G至少相差0.1pp，Union不下降。
- 最佳和末步排序反转标记不稳定，不据此自动追加或修改训练。位置与粒度结论遇反转保留未定。

输出最佳/末步总体、19类前景和背景、有效病例数、逐病例、合并组织、全组配对差值及验证曲线CSV。训练诊断记录损失、共同对齐头的组织预测、伪标签覆盖、门控、注意力熵和实际残差RMS比。诊断对应有标注中心片的更新前前向，门控值记录于参数更新后。缺失指标留空，不计算表面距离。

本轮只筛查位置和表示方向；不能证明统计显著性或医学语义利用。新增参数、共同辅助监督和固定文本编码均需后续独立归因实验。
