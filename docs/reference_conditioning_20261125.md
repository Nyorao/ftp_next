# 参考图像—掩膜条件实验 v2

本实现对应2026-11-24讨论、2026-11-25实施的六组协议。默认只准备实验，不启动正式训练。通过实现检查不代表有效性已验证。

## 模型与数据流

目标三联片保留A的共享编码器和三路CRF。stride8/16（224输入时为256×28×28、256×14×14）的CRF输出生成Q；参考原图经同一个图像编码器生成K。参考原图与20类概率拼成21通道，进入独立16/32/64/128轻量编码器生成V。掩膜不进入共享图像编码器。

Q/K采用通道LayerNorm、128维投影及固定SI正弦位置编码；4头，每头32维。相对行偏置逐头学习，初值为`-0.5*(delta/window)^2`，连续偏移线性插值。窗口固定为stride8的±2行和stride16的±1行。实现先按SI坐标排序，再检索窗口内key；无合法key时参考残差严格为零。

注入为`Fout = Fcrf + tanh(g) * Conv1x1(CA)`。仅门零初始化，输出卷积正常初始化。两个尺度各自使用原始CRF输出，不改变邻片softmax。位置键组把K的图像内容项乘零，其余不变，V仍包含图像。

P1沿AP求20类平均概率，在SI方向保留每类质量，广播后通过`20→32→2C` FiLM作用于同样的stride8/16；最后一层零初始化。它不是位置键KV的数学等价物。

图像张量轴为(AP,SI)，SI为最后一维。原始SI像素中心坐标、参考概率、原图及目标三联片共享仿射；行先验先提取和广播再变换。有效区域随几何运输，填充不作背景证据。概率与坐标不做强度扰动。

CutMix只混合目标影像/伪标签，参考库保持独立。原病例和供体分别计算注意力，使用面积下采样后的CutMix掩膜混合残差；不同病例key不进入同一个softmax。各分支使用对应来源的SI坐标。高分辨率混合边界的面积权重允许两个来源贡献，像素内部只访问自己的来源。

## 冻结教师、GT与选片

参考概率由已有A各自seed42/43/44的6000步`last.pt`教师生成，固定教师不参与梯度或EMA更新。目标模型自己的EMA仍产生原有目标伪标签。缓存生成只调用image-only读取，输出FP16概率，读取后FP32归一化；新卷部署使用相同量化步骤。清单绑定教师、源图像、概率、分区和分辨率哈希。

推理按argmax类别10面积选片；并列时优先接近索引中点，再取小索引；全无椎管时用中点。训练从预测前景面积大于零且至少为病例最大前景面积10%的片中均匀抽取，尽可能排除目标片；空池回退到推理参考。固定参考组始终使用推理参考。抽样随机流为`SeedSequence(seed,epoch,target_index,71349)`，各组配对一致。

GT组仅能读取原1496文件白名单中的实际参考标签。GT不能用于参考等于目标的样本，不能影响选片。每步使用概率为`0.5*max(0,1-step/3000)`，最后3000步全为预测；GT选择独立随机流。GT仅进入学生条件，目标EMA条件始终为预测。记录每次参考名、索引、GT可用数/实际使用数和自参考次数。

## 实验与判定

| 组 | 条件 | 训练参考 | GT |
|---|---|---|---|
| A | 已有三联片基线 | 无 | 原监督 |
| P1 | 行先验FiLM | 随机 | 无 |
| P1-GT | 同P1 | 随机 | 受限课程 |
| KV-pos | 位置键 | 随机 | 无 |
| KV | 图像键 | 随机 | 无 |
| KV-fixed | 图像键 | 椎管面积最大 | 无 |
| KV-GT | 图像键 | 随机 | 受限课程 |

各新组从头训练，6000步、224²、batch8=4L+4U、1496标注/3732影像，warmup600/ramp1200，其他设置沿用A。固定第6000步最终EMA比较；best检查点仍保存，但不用于本实验选模。

六组先跑seed42。Dice比A至少+0.3pp且union-present不降才晋级；最高Dice优先，同分按实际整卷MAC较少，再按表顺序。确认固定包含P1/KV-pos/KV，再加入不同于它们的胜者，最多4组补seed43/44。平均Dice≥+0.3pp、至少2/3种子正向、平均union不降才确认。未通过不自动增加预算。

纯预测KV三种子通过，且分别比P1/KV-pos平均Dice≥+0.1pp、条件错号率不升，才新增KV-cycle。循环仅在完全无标注病例、非自参考配对、未CutMix视图计算：`r→i→r`；教师参考概率detach，中间学生预测保留梯度；参考重建使用置信掩膜软交叉熵，前景阈值.8、背景.95/权重.25，全部像素分母，系数`.1*ramp`。反向查询使用参考自身三联片。seed42比KV≥+0.1pp、union及条件错号率不恶化才补43/44。无3D损失。循环一致并不保证编号正确。

图像—掩膜参考与反向重建借鉴[UniPro](https://arxiv.org/html/2610.06938v2)，其原反向监督使用GT；本实现的无标注教师锚定属于适配，不是官方复现。

## 评价与开销

报告病例等权GT-present/union-present Dice、组织Dice、缺失类误报、前景/背景误差，以及：同组织错号/全部GT编号体素、同组织错号/组织正确编号体素、组织覆盖率。椎体/椎间盘分别保留错一节和错多节计数。

固定m为索引中点，按到m及到实际主参考r*的物理距离≤5、5–15、>15mm分层；干预期间分层不变，另存实际参考排除指标。先累积病例内原生网格混淆矩阵，不把切片当独立病例。

诊断包括中点、同病例随机参考、其他病例、关闭分支和SI平移四分之一长度。随机控制种子1701/1702/1703。统计时先病例内平均随机重复，再重采样病例；三种子先病例内平均种子配对差值，再做10000次bootstrap。

注意力保存逐病例/尺度/头的delta-y质量、均匀有效窗口基准、偏移、熵、边缘质量、门与残差RMS；生成PNG/SVG分布图和错号散点图。硬窗口造成的集中不直接视为有效对应。

开销包含冻结A整卷选片、候选编码/解码/注意力及参考K/V构建。参数、Conv/Linear和attention矩阵乘MAC单列；未计归一化、softmax、索引、插值及反向，不称总FLOPs。已有A训练成本、缓存成本、每候选训练耗时均保留原始记录。参考K/V每卷只计算一次；目标编码使用有界滚动缓存。

## 入口与产物

准备（默认不训练）：

```sh
/home/zhp/.conda/envs/mamba/bin/python experiments/run_reference_conditioning.py \
  --output-dir outputs/reference_conditioning_20261125
```

显式启动已准备快照：

```sh
/home/zhp/.conda/envs/mamba/bin/python experiments/run_reference_conditioning.py \
  --output-dir outputs/reference_conditioning_20261125 --launch-prepared
```

`--screen-only`仅做首轮；`--baselines`支持seed到已有A目录的JSON映射。默认验证所有A配置、划分、完整21例和最终步数，并对新旧源码执行两步合成训练精确比较。正式worker只能运行冻结源码，要求CUDA，不自动回退CPU或重试。

输出含冻结code、geometry、configs/seed42..44、manifest、architecture、baseline_replay、command和status。运行后增加training、analysis、results、report及cache_manifests。每seed临时概率缓存用完后仅删除带本轮owner标识的目录，保留全部来源哈希。冻结入口的`--rebuild-cache 42`等可重建对应缓存供追加诊断。已有数据、旧实验和标签文件不删除。

单个训练支持原`train.py --resume`恢复；自动编排失败时保存失败状态，不自行重试。新增参考配置默认关闭，旧检查点继续加载。部署使用原`predict_spine.py`，可用`--reference-teacher`指定搬迁后的同哈希A权重；不依赖训练缓存或任何标签，实际需要两套权重。

测试入口：`python -m unittest discover -s tests -p test_reference_conditioning.py -v`。合成训练仅验证链路、梯度及恢复；正式性能结论等待GPU实验。
